# Licences of the map assets

Fonts and sprites of https://github.com/protomaps/basemaps-assets at commit 028c18f713baecad011301ff7a69acc39bcc2ae7. Every file here except this one is a byte-for-byte copy of the file of that name in the commit, and is listed with its sha256 in SHA256SUMS. The copy holds only what the styles of `scripts/build-map-style.ts` (flavour `white`) reference: the three font stacks they name and the `white` sprites.
