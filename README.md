# Museumjaarkaart (code name mjk)

A public NL/EN website about the museums of the Netherlands: a catalogue of all ~1,360 museums with search, filters and a map; a personal museum passport (visit log, progress against the Museumkaart list, wishlist); ratings and reviews tied to a logged visit, with photos; public profiles. Sign-up starts as an invite-only beta.

The public brand and domain are not chosen yet. "Museumjaarkaart" is only the repository name.

**Status:** planning. The plan lives in [`docs/plan/`](docs/plan/README.md), decisions in [`docs/adr/`](docs/adr/), the agent manual in [`CLAUDE.md`](CLAUDE.md). Work will be tracked phase by phase under a Roadmap issue (PHASES §5).

Not affiliated with the Museumvereniging or the Museumkaart.
